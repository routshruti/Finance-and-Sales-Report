# Overview

This project leverages Microsoft Excel as a powerful Business Intelligence tool to deliver actionable insights through dynamic reports. Using Power Pivot, DAX, and Pivot Tables, the project covers two main areas: Sales Analytics and Finance Analytics.

# Purpose

## Sales Analytics

### Objective:
Develop a Customer Performance Report and compare Market Performance vs Sales Targets.

### Importance:
Helps businesses monitor sales activities, identify trends, and track key performance indicators (KPIs).

### Key Benefits:
- Optimize customer discount strategies.
- Support sales negotiations.
- Uncover opportunities for market expansion.

## Finance Analytics

### Objective:
Build Profit and Loss (P&L) Reports segmented by Fiscal Year, Month, and Market.

### Importance:
Assists in evaluating financial performance, planning budgets, and aligning with strategic goals.

### Key Achievements:
- Benchmark against industry peers.
- Improve budgeting and forecasting.
- Build confidence in financial health and reporting.
